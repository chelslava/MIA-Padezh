# v0.5.0 — нейро-fallback (MIA.Padezh.Neural)

## Архитектура

Правила остаются в приоритете. Новый пакет `MIA.Padezh.Neural` подключается
опционально: модель вызывается только когда для слова не нашлось ни одного
правила (ядро сообщает это через `Padezh.TryDecline`).

- Модель: char-level GRU seq2seq (Emb 64, hidden 192, ~0,5 млн параметров);
  вход — фамилия + эмбеддинги рода и падежа (подмешиваются в начальное
  состояние декодера); выход — форма, жадное декодирование до 32 символов.
- Обучение: корпус petrovich-eval, 97 860 пар train / 3 120 holdout
  (разбиение по леммам), 12 эпох на CPU; энкодер на `pack_padded_sequence`
  (финальное состояние — на истинном конце последовательности, без PAD-шагов).
- Экспорт: `encoder.onnx` (один проход) + `decoder.onnx` (один шаг),
  авторегрессия на C# (Microsoft.ML.OnnxRuntime). Паритет с PyTorch —
  точность ONNX совпадает с тренировочной до 0,1 п.п.
- Модели и словарь встроены в сборку; регистр входа восстанавливается.

## Честные метрики

- **Модель соло, полный holdout (3 120 пар): 91,2 %.** Остаток — редкие
  экзотические стемы (Авксентюк, Альбрехтс), где модель достраивает
  невиданные биграммы. Порог в тестах — 85 %.
- **Гибрид end-to-end (DeclineLastName): 100 %** на демо-подвыборке и
  99,88 % на полном корпусе — правила покрывают всё кириллическое.
- **Важное наблюдение: правила покрывают 1 500/1 500 (100 %) форм
  holdout-словаря** — для любой кириллической фамилии найдётся суффиксное
  правило. Практический сценарий модели — вход вне алфавита правил
  (латиница, спецсимволы) и точка расширения для будущих режимов
  (нейро-арбитр для спорных классов: «Фрейндлих», «Кучма»).

## API

```csharp
using var padezh = new NeuralPadezh();

// гибрид: правила в приоритете
padezh.DeclineLastName("Иванов", Case.Genitive);   // «Иванова» — правило

// прямой вызов модели (для экспериментов)
padezh.DeclineRaw("шварценеггер", Case.Genitive, Gender.Male); // «шварценеггера»
```

Ядро MIA.Padezh не изменило публичный API (кроме добавления
`Padezh.TryDecline`) и не получило зависимостей; ONNX-зависимость живёт
только в MIA.Padezh.Neural (net8.0 + net10.0).

## Обучение

Скрипты в `training/`: `prepare_data.py` → `train.py` (чекпоинт +
анализ промахов) → `export_onnx.py` → `verify_onnx.py` (паритет ONNX).
