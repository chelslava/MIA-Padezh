# v1.3 — церковный звательный и множественное число имён/отчеств

## 1. Церковный звательный: `VocativeStyle.Church`

Опциональный стиль обращений (перегрузки `Decline`, `DeclinePart`,
`RuName.Decline`, `RuName.DeclinePart`):

| Род | Правило | Примеры |
|---|---|---|
| муж. | согласный → +е | Пётр → **Пётре**, Иван → Иване, Александр → Александре |
| муж. | -й/-ь → -е | Николай → **Николае**, Игорь → **Игоре**, Дмитрий → Дмитрие |
| муж. | -а → -о, -я → -е | Данила → **Данило**, Никита → **Никито**, Илья → **Илье** |
| жен. | -а → -о | Анна → **Анно**, Ольга → **Ольго**, Вера → **Веро** |
| жен. | -ия / -я после гласной → -е | Мария → **Марие**, София → Софие, Зоя → **Зое** |
| жен. | -я после согласной или ь → -о | Дарья → **Дарьо** |
| жен. | -ь → -и | Любовь → **Любови** |

Андрогинные имена склоняются по мужской модели (Саша → Сашо). Фамилия и
отчество в звательном не изменяются (обращение «Иванов Пётре!»).
Стиль по умолчанию — разговорный (`VocativeStyle.Colloquial`), прежнее
поведение не изменилось.

## 2. Множественное число имён и отчеств

`data/plural.json` дополнен секциями firstname/middlename; `DeclinePlural`
теперь работает для всех трёх частей ФИО:

| Класс | Им. мн. | Род. мн. | Твор. мн. |
|---|---|---|---|
| Иван (согласная) | Иваны | Иванов | Иванами |
| Пётр | Пётры | Петров? — Пётров | Пётрами |
| Николай (-й) | Николаи | Николаев | Николаям |
| Игорь (-ь) | Игори | Игорей | Игорями |
| Анна / Вера (-а) | Анны / Веры | Анн / Вер | Аннами / Верами |
| Мария / Зоя (-я после гласной) | Марии | Марий | Мариями |
| Оля (-я после согласной) | Оли | Оль | Олями |
| Дарья (-ья) | Дарьи | Дарь | Дарьями |
| Иванович (-ич) | Ивановичи | Ивановичей | Ивановичами |
| Ивановна (-на) | Ивановны | Ивановн | Ивановнами |

Неизменяемые формы (Левко, Агидель) — без изменений. Жена-класс имён на -ь
с беглой гласной (Любовь) оставлен без изменений (спорная норма).
`RuName.DeclinePlural` по-прежнему возвращает форму «семья» (только фамилия).
