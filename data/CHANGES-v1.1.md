# v1.1 — множественное число, звательный падеж, словарь пола

## 1. Множественное число фамилий (`DeclinePlural`)

Парадигмы заданы в `data/plural.json` (в корпусе petrovich-eval форм мн.ч. нет,
классы определены по академической норме) и скомпилированы в код:

| Класс | Им. мн. | Род. мн. | Твор. мн. |
|---|---|---|---|
| Иванов / Иванова | Ивановы | Ивановых | Ивановыми |
| Толстой / Толстая | Толстые | Толстых | Толстыми |
| Скворцовский / Скворцовская | Скворцовские | Скворцовских | Скворцовскими |
| Шмидт, Беккер, Дуб (согласная) | Шмидты | Шмидтов | Шмидтами |
| Кузнец (беглая гласная) | Кузнецы | Кузнецов | Кузнецами |
| Кашенок | Кашенки | Кашенков | Кашенками |
| Бабаец (аец/иец/еец) | Бабайцы | Бабайцов | Бабайцами |
| Шевченко, Черных, Бильжо, Данелия (ж) | без изменений |

Орфография велярных учена: после к/г/х/ж/ш/ч/щ — «ие/их/им/ими» (Ильинские,
а не «Ильинскые»). Неизменяемые классы (-енко, -их/-ых, конечная гласная,
женские фамилии-существительные типа Чайка) и мужские -а/-я во мн.ч. — без
изменений (безопасный дефолт). Женские формы (-ова/-ина) распознаются по
суффиксам сами, подсказка рода не обязательна. Поддерживается только фамилия
(реальный сценарий — «семья Ивановых»); для имени/отчества бросается
`NotSupportedException`.

## 2. Звательный падеж (`Case.Vocative`)

Современный разговорный звательный — продуктивное усечение:
- конечное **-а** → усекается: Саша → **Саш**, Миша → **Миш**, Вера → **Вер**;
- конечное **-я после согласной** → заменяется на **ь**: Ваня → **Вань**, Катя → **Кать**, Оля → **Оль**;
- слова на согласный, -й, -ь и на -я после гласной не меняются: Пётр, Игорь, Мария, Зоя, Илья.

Применяется только к именам; фамилия и отчество в звательном остаются без изменений
(обращение «Иванов Пётр!» не склоняется). Церковный стиль (Пётре, Николае) не
реализован — добавим по запросу отдельной перегрузкой.

## 3. Словарь пола имён (`data/gender-names.json`, 1 765 записей)

Добыт из корпуса petrovich-eval: леммы с однозначным родом (7 792 мужские,
4 910 женские, 18 двуродовые леммы в корпусе), детект которых невозможен
суффиксными правилами (Агидель, Ермек, Джудит, Никита, Арлен…). Проверка —
точное совпадение слова, бинарный поиск по отсортированному массиву, между
исключениями и суффиксными правилами.

Эффект: авто-детект пола имён на корпусе 98,78 → **99,63 %** (ошибки суффиксного
детекта для непокрытых имён устранены). Двуродовые леммы (Женя, Саша) помечены
андрогинными — детект честно возвращает `Androgynous`.
